# 이것이 취업을 위한 코딩 테스트다

이 폴더는 책의 장·절 흐름을 그대로 따라가며 예제 풀이를 보관합니다. 파일을 장별 하위 폴더에 나누고, 파일명 앞에 두 자리 장·절 번호를 붙여 탐색과 정렬이 일관되게 되도록 합니다.

## 장별 예제

| 장 | 주제 | 폴더 | 예제 수 |
|---|---|---|---:|
| 03 | 그리디 | [chapter-03-greedy](chapter-03-greedy/) | 7 |
| 04 | 구현 | [chapter-04-implementation](chapter-04-implementation/) | 4 |
| 05 | DFS/BFS와 기본 자료구조 | [chapter-05-dfs-bfs](chapter-05-dfs-bfs/) | 11 |
| 06 | 정렬 | [chapter-06-sorting](chapter-06-sorting/) | 1 |
| 07 | 이진 탐색 | [chapter-07-binary-search](chapter-07-binary-search/) | 1 |

예제 파일명은 `장-절-예제번호_주제.py` 형태입니다. 예제가 하나면 `03-01`, 같은 절의 서로 다른 예제라면 `03-02-1`, `03-02-2`처럼 구분합니다. 절 번호가 다른 예제는 원래 책의 번호를 보존합니다.

```text
chapter-03-greedy/
├─ 03-02-1_큰_수의_법칙.py
└─ 03-02-2_큰_수의_법칙.py
```

예제 파일에는 책의 풀이를 각각 독립적으로 보관합니다. 풀이 방식이 달라지는 경우 원본 예제 파일을 덮어쓰지 말고 `..._반복문.py`처럼 방식을 추가해 별도 파일로 둡니다.
