# 이것이 취업을 위한 코딩 테스트다

이 폴더는 책의 장·절 흐름을 따라 예제 풀이를 보관합니다. 예제 파일은 장별 하위 폴더에 두고, 파일명은 `6-3 삽입 정렬.py`처럼 번호와 제목을 공백으로 구분합니다. 제목에는 밑줄 대신 공백을 씁니다.

## 장별 예제

| 장 | 주제 | 폴더 | 예제 수 |
|---|---|---|---:|
| 3 | 그리디 | [chapter-03-그리디](chapter-03-그리디/) | 7 |
| 4 | 구현 | [chapter-04-구현](chapter-04-구현/) | 4 |
| 5 | DFS/BFS와 기본 자료구조 | [chapter-05-dfs-bfs](chapter-05-dfs-bfs/) | 11 |
| 6 | 정렬 | [chapter-06-정렬](chapter-06-정렬/) | 3 |
| 7 | 이진 탐색 | [chapter-07-이진-탐색](chapter-07-이진-탐색/) | 1 |

한 절에 예제가 여러 개 있으면 `3-2-1`, `3-2-2`처럼 절 번호 뒤에 예제 번호를 붙입니다. 절 번호가 서로 다른 예제는 책의 원래 번호를 유지합니다.

```text
chapter-03-그리디/
├─ 3-2-1 큰 수의 법칙.py
└─ 3-2-2 큰 수의 법칙.py
```

풀이 방식이 달라지는 경우에도 원본 예제는 그대로 두고 `6-3 삽입 정렬 반복문.py`처럼 제목 뒤에 방식을 덧붙여 별도 파일로 보관합니다.
