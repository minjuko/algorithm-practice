# 백준 풀이

문제 풀이를 현재 난이도 폴더에 모읍니다.

```text
baekjoon/
├─ bronze/
├─ silver/
└─ gold/
```

파일명은 `{문제번호}_{백준문제명}.py`로 통일합니다. 문제 번호로 먼저 찾고, 제목으로도 확인할 수 있도록 문제명을 생략하지 않습니다. 같은 문제를 다시 풀면 `_bfs`, `_dp`처럼 풀이 방식을 이름 뒤에 붙입니다.

```text
silver/1012_유기농_배추.py
gold/2293_동전_1.py
```

난이도는 저장 시점의 백준/solved.ac 등급을 기준으로 분류합니다. 문제 등급이 바뀌거나 기존 분류가 잘못된 것을 발견하면 해당 폴더로 파일을 이동합니다. 새 등급 폴더가 필요해지면 같은 방식으로 추가합니다.
