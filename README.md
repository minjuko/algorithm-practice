# Algorithm Practice

Python 중심의 알고리즘·자료구조 및 SQL 문제 풀이를 정리한 학습 저장소입니다.

## 학습 방식

- 프로그래머스·백준 문제를 주제와 난이도별로 분류합니다.
- 풀이 코드를 문제번호와 제목으로 관리하고 Git 커밋으로 학습 기록을 남깁니다.
- 같은 문제를 다른 알고리즘으로 풀었다면 파일명에 풀이 방식을 구분합니다.

## 사용 방법

`solutions/`와 `books/`에서 원하는 문제의 풀이 파일을 열어 확인할 수 있습니다. Python 풀이 파일은 Python 3 환경에서 개별 실행합니다.


## 저장소 구조

```text
.
├─ solutions/
│  ├─ programmers/
│  │  ├─ level-0/
│  │  ├─ level-1/
│  │  ├─ level-2/
│  │  ├─ level-3/
│  │  ├─ pcce/
│  │  ├─ kit/
│  │  └─ sql/
│  ├─ baekjoon/
│  └─ joonlab/
├─ books/
│  └─ this-is-coding-test/
├─ education/           # 교육 프로그램 문제 풀이, Git 추적 제외
├─ playground/          # 문제 풀이가 아닌 간단한 코드 연습
└─ blog/                # 티스토리 작성용 글, Git 추적 제외
```

## 파일명 규칙

```text
{문제번호}_{문제명}.{확장자}
```

파일명의 공백은 `_`로 구분한다.

```text
161989_덧칠하기.py
12917_문자열_내림차순으로_배치하기.py
```

같은 문제를 다른 알고리즘으로 다시 풀었다면 풀이 방식을 파일명 뒤에 붙인다.

```text
42861_섬_연결하기.py
42861_섬_연결하기_kruskal.py
```
